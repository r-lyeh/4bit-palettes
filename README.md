# Palettes
4-bit palettes for the ZX Sinclair Spectrum computer. Extracted from [Spectral emulator](https://github.com/r-lyeh/Spectral).

Each palette entry contains:
- A JASC 0100 .pal file,
- A compatible ZX Spectrum .tap file (ULA+)
- Image collage using the top100 voted artwork from [zxart.ee website](https://zxart.ee) (in random order)
